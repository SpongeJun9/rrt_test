# 05 论文试验与结果整理

## 固定实验口径

每次任务只规划一次；路径加密保留原折点，只在原线段上插入点，不重新搜索、不更换终点。执行期间的新障碍由原控制器检测并可能停车，不绕障重规划。动态环境避障能力不是本版 RAG 单次静态地图试验的已验证结论。

完整入口支持任务结束后再次人工给 Goal；每个目标是一条独立试验记录，种子不会自动更换。正式对照试验仍应人工复位至同一标记起点，再给同一目标，不能把连续点击产生的不同起点数据直接混比。

正式采集前冻结：地图文件及校验和、方法版本、随机种子序列、迭代预算、车体尺寸/净空、速度、控制器、Goal Checker、起终点和失败判定。调试数据与正式数据分开。每次人工复位到同一标记起点，记录定位误差；不能把上一方法终点当下一方法起点。

同时冻结 `nav_profile`。完整启动默认 original，保留原导航参数与其配置的外廓；validation 才使用此前低速和预设外廓。三个对照算法必须使用同一 profile、相同地图和相同净空，不能用缩小半径后的成功率与旧 10 格净空结果混比。

RViz 适合操作验收。正式比较需准确重复目标时，使用原独立入口的 `--goal-x X --goal-y Y --goal-yaw R`，数值来自预先记录的同一 map 坐标系；不用每次凭鼠标点击近似位置。完整系统仍需运行，独立入口不得与 full_stack 内的 runner 同时运行。

## 结果文件

| 文件 | 用途 |
|---|---|
| `metadata.json` | 阶段、状态、实际起点、配置、地图校验和、执行指标与异常原因 |
| `rviz_goal.json` | 从 RViz 接收的首个目标，仅位姿输入模式生成 |
| `map.json` | 本次静态地图快照 |
| `navigation_parameters.json` | 读回的控制器、平滑器与代价地图参数 |
| `planner_response.json` | 本次规划结果和 PlannerMetrics，保留失败 |
| `reference_path.json` | 实际交给控制器的完整参考路径 |
| `estimated_trajectory.csv` | 来自正常定位 TF 的估计行驶轨迹 |
| `estimated_trajectory.partial.csv` | 异常退出时可用的追加轨迹 |
| `action_result.json` | FollowPath 终止状态与可用结果字段 |
| `feedback.json`、`last_command.json` | 执行反馈和速度观测 |

文件由执行阶段决定，不是每次都全部存在。完整入口应把终端输出保存为会话日志：

```bash
mkdir -p ~/rag_rrt_logs
bash scripts/start_trial.sh world:=rmul2026 2>&1 | \
  tee "$HOME/rag_rrt_logs/trial_$(date +%Y%m%d_%H%M%S).log"
```

## 指标与限制

规划侧统计总耗时、先验生成耗时、求解耗时、成功率、路径长度、碰撞检查数、树节点数；先验生成必须计入 RAG 总开销。重复试验报告分布和失败次数，不只挑最快/成功结果。首次加载开销也需明确是否包含。

执行侧统计执行成功率、终点平面误差、估计行驶长度、路径跟踪误差和耗时。轨迹来自同一定位系统，不能当独立真值；无接触传感器或独立观测，不据此宣称零碰撞。Action 成功不直接等于论文试验通过，原 runner 还核对终点、实际移动量与停止状态。姿态控制不属于当前默认验证结论。

方法名务必区分：

| 参数 | 方法 |
|---|---|
| `rrt_star` | RRT* 基线 |
| `irrt_star` | Informed RRT* 基线 |
| `rag_bpc_conn_init_rel_only` | RAG-RRT*-Rel |
| `rag_bpc_conn_init_rel_only_topk_fallback` | RAG-RRT*-Rel-TopK-Fallback，当前默认 |

基线仅在需要对照试验时显式选择，规划失败后程序不会自动切换。算法内部 TopK-Fallback 是父节点/重连候选检查机制，不是失败后换用另一算法。

## 可复现记录与归档

在机器人记录版本，不上传私人设备信息或凭据：

```bash
git rev-parse HEAD
printenv ROS_DISTRO
python3 --version
sha256sum ~/sentry_maps/test_site/test_site.yaml \
  ~/sentry_maps/test_site/test_site.pgm \
  ~/sentry_maps/test_site/test_site.pcd
```

按 YAML 实际图像文件名调整上述路径。归档原始结果而非仅保留汇总表：

```bash
python3 rag_rrt_sentry_validation_v1/rag_rrt_sentry_validation_v1/scripts/pack_results.py \
  "$HOME/rag_rrt_real_results"
```

本仓库尚无真实试验结果或论文性能结论。

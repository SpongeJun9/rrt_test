# 06 常见问题

| 现象 | 定位步骤 |
|---|---|
| `Package ... not found` | 新终端加载 `/opt/ros/humble/setup.bash` 和根工作区 install；确认构建阶段无失败；RAG 还需自己的 install |
| `Exec format error` / `Invalid or empty Python entry point` | 停止本次启动，在根目录运行 `bash scripts/build_workspace.sh`；末尾会修复并检查 RAG 入口。仅增加执行权限不能修复空文件 |
| 只有黑白栅格，没有点云 | 使用本包专用 RViz，检查 `Global PCD map`（蓝色）及 `Live registered scan`（黄色）；全局话题 `/relocalization/global_map` 使用 Reliable / Transient Local；日志 `Loaded global map` 只代表内部加载成功 |
| PCD 无法加载/文件很小 | 检查是否 LFS 指针；运行 `git lfs pull`、`git lfs fsck`；检查文件是否来自本轮正常退出的 Point-LIO |
| `FetchContent` 下载失败 | 检查到 GitHub 的网络；small_gicp 从上游拉取，不是切换 ROS 发行版来解决 |
| 缺少消息/头文件/共享库 | 先保留首个编译错误，再对照 package.xml、实际源码和 SDK 架构补依赖；全视觉/仿真并未保证可编译 |
| 没有 `/livox/lidar` | 核对 MID360 配置、网卡 IP、连接、驱动日志与话题名 |
| 没有 `/odometry` 或 TF 超时 | 检查 Point-LIO → loam_interface → sensor_scan_generation；核对实际模型外参和云台关节反馈 |
| 地图与点云错位 / `GICP did not converge` | 确认同轮二维图/PCD、相同安装姿态、真实 TF；保持静止，用 2D Pose Estimate 给实际位置和朝向，等待点云稳定重合后再给目标；不能随意改 origin 掩盖误差 |
| `CHECK_FAIL`/执行预检失败 | 阅读 metadata 的 preflight_issues 和 navigation_parameters；不要绕过检查或人为缩小车体 |
| `differs from original navigation YAML` | original 模式读回参数与本次保存的原配置不一致；检查是否存在同名旧节点、另一个导航启动或参数被在线修改 |
| 速度数组数值一样却报上述不一致 | 已修复 ROS double[] 为 array.array、YAML 为 list 导致的直接比较误报；更新 runner，实际参数值仍严格比较 |
| 黑白地图看不到膨胀 | 勾选专用 RViz 的 Global Costmap / Local Costmap，确认 Color Scheme=costmap；`/map` 是原始地图，没有膨胀颜色；可暂时关闭蓝/黄色点云显示 |
| Goal 后 RViz 立即关闭 | 先看日志是否 `trial status=FAIL` 后由 launch 向 RViz 发送 SIGINT。完整入口已改为保留 RViz/定位并显示任务状态，失败不再关闭整套系统；独立 run_trial.sh 仍在单次完成后退出 |
| 想要原工程的彩色膨胀和雷达显示 | 当前界面基于原 nav2_default_view.rviz，展开 Global Planner / Controller，保留 TerrainMapExt 的原强度着色；附加蓝/黄色 PCD 调试显示默认关闭 |
| `Start is not valid after applying planner clearance` | Goal 已收到且已请求 RAG；检查 metadata 的 actual_start、planner_radius_m 和 map.json。先解决 GICP/TF 对齐，再核对起点周围障碍与未知区；original 沿用原配置半径，validation 使用预设外廓，不能只换目标绕过起点错误 |
| 选择目标后没反应 | 等待输入/Ready 提示；使用专用 SetGoal 工具及 `/rag_rrt/goal_pose`；原 Nav2 GoalTool 不适用；当前任务处理中点击被忽略，任务结束后再次人工点击会开启新任务，停止未确认时需先处理原任务 |
| 目标/路径不可用 | 核对净空、地图边界、未知区域、目标合法性与预算；失败记录保留，禁止自动更换种子掩盖失败 |
| 车到不了/弯道切角 | 核对路径加密、跟踪器前瞻和实际速度；保留失败记录，修改参数后重新定义试验批次 |
| `another navigation goal is active` | 关闭其他导航客户端或自动决策，避免两个程序同时控制 FollowPath |
| 斜向命令超速 | 完整入口已限制平滑器各轴为 cap/sqrt(2)；独立运行原系统需核对最终 `/cmd_vel` |
| 中止后仍在动 | 查看取消结果和停止观测；`STOP NOT CONFIRMED` 时按原方式接管/急停；下位机独立自旋不受上位机参数控制 |
| Ctrl+C 后没有新 PCD | 核对 Point-LIO 是否正常退出、写入目录权限和编译源码路径；不能把旧 scans.pcd 当新图 |

提供问题日志时附：执行命令、首个完整错误、节点列表、相关配置和结果目录。日志中出现凭据或个人数据先脱敏；不需要发送密码、令牌或私钥。

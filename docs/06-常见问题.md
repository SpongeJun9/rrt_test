# 06 常见问题

| 现象 | 定位步骤 |
|---|---|
| `Package ... not found` | 新终端加载 `/opt/ros/humble/setup.bash` 和根工作区 install；确认构建阶段无失败；RAG 还需自己的 install |
| PCD 无法加载/文件很小 | 检查是否 LFS 指针；运行 `git lfs pull`、`git lfs fsck`；检查文件是否来自本轮正常退出的 Point-LIO |
| `FetchContent` 下载失败 | 检查到 GitHub 的网络；small_gicp 从上游拉取，不是切换 ROS 发行版来解决 |
| 缺少消息/头文件/共享库 | 先保留首个编译错误，再对照 package.xml、实际源码和 SDK 架构补依赖；全视觉/仿真并未保证可编译 |
| 没有 `/livox/lidar` | 核对 MID360 配置、网卡 IP、连接、驱动日志与话题名 |
| 没有 `/odometry` 或 TF 超时 | 检查 Point-LIO → loam_interface → sensor_scan_generation；核对实际模型外参和云台关节反馈 |
| 地图与点云错位 | 确认同轮二维图/PCD、相同安装姿态、真实 TF；初始位姿用 2D Pose Estimate，不能随意改 origin 掩盖误差 |
| `CHECK_FAIL`/执行预检失败 | 阅读 metadata 的 preflight_issues 和 navigation_parameters；不要绕过检查或人为缩小车体 |
| 选择目标后没反应 | 等待输入提示；使用专用 SetGoal 工具及 `/rag_rrt/goal_pose`；原 Nav2 GoalTool 不适用；首个目标已冻结时后续点击被忽略 |
| 目标/路径不可用 | 核对净空、地图边界、未知区域、目标合法性与预算；失败记录保留，禁止自动更换种子掩盖失败 |
| 车到不了/弯道切角 | 核对路径加密、跟踪器前瞻和实际速度；保留失败记录，修改参数后重新定义试验批次 |
| `another navigation goal is active` | 关闭其他导航客户端或自动决策，避免两个程序同时控制 FollowPath |
| 斜向命令超速 | 完整入口已限制平滑器各轴为 cap/sqrt(2)；独立运行原系统需核对最终 `/cmd_vel` |
| 中止后仍在动 | 查看取消结果和停止观测；`STOP NOT CONFIRMED` 时按原方式接管/急停；下位机独立自旋不受上位机参数控制 |
| Ctrl+C 后没有新 PCD | 核对 Point-LIO 是否正常退出、写入目录权限和编译源码路径；不能把旧 scans.pcd 当新图 |

提供问题日志时附：执行命令、首个完整错误、节点列表、相关配置和结果目录。日志中出现凭据或个人数据先脱敏；不需要发送密码、令牌或私钥。

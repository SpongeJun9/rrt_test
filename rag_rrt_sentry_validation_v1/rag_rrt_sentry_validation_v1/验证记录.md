## 与旧代码的区别

使用三包的独立工作区：自定义接口、含算法数据的 Python 后端、Python 单次实验节点。没有把旧 Jazzy C++ 执行节点作为部署依赖，从而避免其直接访问 Humble 不存在的字段。

算法核心原样保留；外部地图对象统一使用保守的跨栅格边检查，适配器仍执行最终输出复核。此前候选包仅在输出处拒绝部分路径，本包将同一检查纳入三方法搜索使用的地图对象，以避免搜索与输出检查口径不一致。不能与旧 P3 碰撞检查数字直接混报。

交付文件是完整可编译源码包，仍需设备操作者执行首次编译、只读检查和短任务验收。执行默认关闭，只有明确的 --execute 才发送目标。
